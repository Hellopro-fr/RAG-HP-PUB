## Ce qui bascule dans ce lot

- **agent-service** : les appels du BO (Ecritel) via `https://api.hellopro.eu/agent-service/agents/{code}/run` partent vers Cloud Run (22 à 109 requêtes par jour du 05 au 07/10).
- **mcp-hellodata-service** : les appels des clients MCP (via mcp-gateway) partent vers Cloud Run.

## À savoir, service par service

| Service | Vigilance |
|---|---|
| `agent-service` | Python FastAPI + LangGraph, **sans état**, sans authentification (F-HP-SEC-033 : entrée interne sur Cloud Run). Sorties : API v2 PHP `api.hellopro.fr` (Ecritel, `HP_TOKEN`) + OpenAI, Anthropic, Gemini, DeepSeek → **`all-traffic`** (IP NAT statique `35.233.35.8`). Appels au modèle jusqu'à 300 s → **délai Cloud Run 600 s** (nouvelle entrée `request_timeout`). `MCP_GATEWAY_URL` / `MCP_CLIENT_*` **vides** sur la VM → non passés. |
| `mcp-hellodata-service` | Go, bibliothèque standard seule. **`max=1`** : liens CSV signés gardés en mémoire. Autorisation par **en-têtes non signés** de mcp-gateway → frontière élargie au VPC sur Cloud Run, **acceptée** (option A, **F-HP-SEC-034**). Sorties : `bo.hellopro.fr` et `www.hellopro.fr` (Ecritel) → `all-traffic`. |
