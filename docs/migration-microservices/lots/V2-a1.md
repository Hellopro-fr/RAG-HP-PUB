## Ce qui bascule dans ce lot

- Les appels **passant par la gateway VM** (`api.hellopro.eu` → `api-gateway-go`) pour ces 4 routes partent vers Cloud Run.
- Rien d'autre : pas de DNS, pas de base, pas de broker. Les appels **directs** entre conteneurs de la VM restent sur les jumeaux.

## Prérequis spécifiques au lot (en plus de la procédure commune)

- Wrappers CD au réglage cible (entrée interne, appel anonyme, `min_instances: 1`) **mergés** — sinon le prochain CD rouvre l'accès public.
- Smoke test du CD qui ignore l'entrée interne (`fix/cd-smoke-internal-ingress`, 02/10) — sinon le CD fait un retour arrière automatique.
- Un dev testeur par service (tableau ci-dessous).

## Ce qu'on attend des devs concernés

| Service | Dev testeur | Parcours à jouer après la bascule |
|---|---|---|

Le dev écrit **OK / KO** dans le canal de bascule ~5 min après la bascule de son service. Aucune commande à lancer.
